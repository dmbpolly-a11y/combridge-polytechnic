========================================
INFINITYFREE DEPLOYMENT GUIDE
========================================

FOLDER READY: infinityfree-complete

This folder contains EVERYTHING needed to run on InfinityFree:
- All Laravel files
- Vendor folder (Composer dependencies)
- .env configuration
- .htaccess files
- index.php and index.html redirects
- Storage directories

========================================
UPLOAD INSTRUCTIONS
========================================

METHOD 1: FTP Upload (RECOMMENDED)
----------------------------------
1. Get FTP credentials from InfinityFree control panel
2. Open FileZilla or WinSCP
3. Connect to your FTP
4. Upload ALL files from 'infinityfree-complete' folder to 'htdocs'
5. Wait for upload to complete (may take 10-30 minutes due to vendor folder)

METHOD 2: File Manager + ZIP
----------------------------
1. Compress 'infinityfree-complete' folder into a ZIP
2. Login to InfinityFree File Manager
3. Upload ZIP to htdocs
4. Extract the ZIP
5. Move all files from extracted folder to htdocs root

========================================
AFTER UPLOAD - IMPORTANT STEPS
========================================

Step 1: Set Folder Permissions
------------------------------
In File Manager, set these folders to 777 permissions:
- storage (and ALL subfolders)
- bootstrap/cache

Right-click folder ? Permissions ? 777 (or rwxrwxrwx)

Step 2: Verify Files
--------------------
Make sure these files exist in htdocs:
? .env
? .htaccess
? index.html
? index.php
? artisan
? composer.json
? /public/index.php
? /vendor/ (folder with many files)

Step 3: Test Your Site
----------------------
Visit: http://combrige-polytechnic.66ghz.com

========================================
TROUBLESHOOTING
========================================

ERROR: 403 Forbidden
Fix: Make sure index.html and index.php exist in root

ERROR: 500 Internal Server Error
Fix: Set storage and bootstrap/cache permissions to 777

ERROR: Blank Page
Fix: Check .env file exists and APP_KEY is set

ERROR: Database Connection Failed
Fix: Verify database credentials in .env match your InfinityFree database

ERROR: Class not found
Fix: Make sure vendor folder uploaded completely

========================================
IMPORTANT NOTES
========================================

1. First load may be slow (InfinityFree free tier)
2. Do NOT delete .env file
3. Keep vendor folder intact
4. Storage folder needs 777 permissions
5. Your database is already configured in .env
